  `TOASTS.openSource` is gone.

- **Icons** take their colour from the active palette when the caller passes none,
  so the nine files P8 listed as dark-token debt are now themed.

### A bug the tests caught

The first sources test failed with "1 aktif" ≠ actual. With no stored preference
(`enabledSourceIds === null`) the screen treated everything as on, but
`useEnabledSources().setEnabled` computes from `current ?? []` — so turning *one*
source off while nothing was stored persisted `[]` and switched **every** source
off at once. The screen now materialises the default before the first toggle and
writes the whole next list (`app/(tabs)/sources.tsx:25-45`). The fix is in the
screen because `src/user-state/**` is P6-owned and forbidden here.

## 6. Decisions

1. **Asked before widening a forbidden path.** The brief wanted a category picker,
   but `addSourceByUrl(url)` had nowhere to put one and `src/data-access/**` is
   forbidden. The coordinator authorised the minimal signature
   `addSourceByUrl(url, options?: {category?, language?})`, threaded into the
   existing Edge body across the interface and both adapters — ~6 lines, no other
   change in that tree. The method is `addSourceByUrl`, not `addCustom` (the
   brief's wording was loose; confirmed).
2. **`src/data/**` kept.** See §4 — deleting it would have required writing inside
   `src/data-access/**`.
3. **Saved list reads the feed cache.** Saved ids are device-local; the bodies come
   from the feed query rather than N per-id round trips. The consequence is honest
   and worth stating: an article that has aged out of the feed page will not appear
   in Saved until a `getArticle`-per-id path exists.
4. **Toast is a provider, not a store.** Four messages survive; the provider owns
   `{id, text}` and one 2.2 s timer keyed to the id, so a replacement toast cannot
   be dismissed by the previous one's clock.
5. **Icons resolve their own colour.** A `useIconColor(color, slot)` helper means a
   caller may still pass an explicit palette colour (Settings does) while an
   unstyled icon is never a dark-token glyph on a light screen.
6. **Feed `sourceIds` is omitted, not `[]`, when nothing is enabled yet** — an
   empty array asks for a feed with no sources at all.
7. **Two test compromises, stated rather than hidden.** The user-state hooks write
   through the module-level `kv` singleton (P6-owned), so screen tests reset real kv
   keys in `beforeEach` instead of injecting a fake, and assert *visible* state
   (the bookmark flips, the active count drops) rather than storage bytes — P6's own
   tests already cover the storage round-trip. And the offline-stale test uses a
   `retryable:false` error so the hook's retry policy settles the query at once;
   the condition under test is `isError` + cached rows, not retry timing.

## 7. Not verified

- **Nothing native, nothing on a device.** No iOS/Android run, no `expo start`.
  Every assertion is a Jest render in `jest-expo`'s environment or a web export.
  Untested there: `Linking.openURL` actually opening a browser, `RefreshControl`
  gesture behaviour, `FlatList` `onEndReached` under a real scroll, `Modal`
  presentation for both sheets, and keyboard behaviour in the search and
  add-source inputs.
- **No real data has ever flowed through these screens.** Every table is still
  empty (P6 measured `200 []`), so the mapper→screen path has only run over
  fabricated rows. Pagination is tested with a two-page fake, not a real keyset
  walk over thousands of articles.
- **Edge endpoints are still not deployed** — `add-source` was 404 at P6 time.
  The add-source sheet's success path has never met a real function; only its
  error mapping is exercised.
- **Visual parity is unmeasured.** No 390×844 check, no screenshots, no
  side-by-side against the prototype. "Pixel-equivalent in mock mode" is a design
  intent here, not a measurement — string parity and structure are what A6/A2
  actually prove.
- **Light theme across the migrated screens is untested visually.** The palette is
  wired everywhere now (A5 is clean), but no test renders a screen in light mode
  and nobody has looked at one.
- **Accessibility** beyond roles/labels/state: no screen-reader pass, no focus
  order, no dynamic-type check.
- The `useEnrichment` poll loop (`poll_after_seconds`, stop after N) is P6 code
  exercised here only through its `queued` result; the timing is not tested.
