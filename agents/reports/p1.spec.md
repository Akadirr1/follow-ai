## Goal
Introduce the seam every later client task builds on, without changing behaviour:
- **Domain DTOs** (`src/domain/*.ts` or `src/data-access/types.ts`): `Source`,
  `Article` (with `summary?: {bullets:[string,string,string]; translationTr: string|null;
  translationState:'ready'|'not_required'|'pending'}`), `Digest`, `DigestItem`, a
  `Cursor` opaque type `{publishedAt:string; id:string}`, `Page<T>`.
- **Repository interfaces** (versioned): `FeedRepository` (list page by cursor +
  source ids + category, get article, search), `SourceRepository` (list defaults,
  add custom by URL → returns Source or a typed error), `DigestRepository` (latest
  digest or `{status:'preparing'}`), `EnrichmentRepository` (request summary →
  `ready|queued`). Return DTOs, never Supabase rows. Errors are typed
  (`DataError{code, retryable, message}`), never thrown strings.
- **Config** (`src/config/env.ts`): validate `EXPO_PUBLIC_DATA_MODE` (`mock` |
  `supabase`, default `mock`), `EXPO_PUBLIC_SUPABASE_URL`,
  `EXPO_PUBLIC_SUPABASE_ANON_KEY` (required only when mode=`supabase`; when
  missing, fall back to `mock` **with a `console.warn`** naming the variable).
  Expose a frozen object; never read `process.env` elsewhere.
- **Mock adapter** (`src/data-access/mock/*.ts`): implements all four repositories
  over the existing `src/data/*.ts` mock data, including cursor pagination over the
  5 articles and a `requestEnrichment` that returns `ready` with the existing `sum`/
  `en` fields. Keep `src/data/*.ts` as-is (screens still import it until P7).
- **Factory** (`src/data-access/index.ts`): `getRepositories()` selects by mode;
  the `supabase` branch is a stub that throws a typed `DataError{code:'not_implemented'}`
  (P6 fills it). No `@supabase/supabase-js` dependency in this task.
- **Env scaffolding:** add the three `EXPO_PUBLIC_*` entries to
  `scripts/env.example` and to `scripts/setup-env.ps1` as non-secret prompts with
  defaults (URL `https://eglxzbsrewbleqlstefd.supabase.co`, anon key from the
  facts file, mode `mock`); secret handling in the script must not change.
  Note: the repo's permission rules block files named `.env*`; the template is
  `scripts/env.example`.
