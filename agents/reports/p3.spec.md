## Goal
- `supabase/migrations/202608210006_seed_default_sources.sql`: the **six** default
  sources (OpenAI Blog, Google DeepMind, Hugging Face, arXiv cs.AI, TechCrunch AI,
  Webrazzi AI) with slug, name, `feed_url` (measured), `feed_url_hash`, `site_url`,
  `language` (`tr` only for Webrazzi), `category` (Modeller / Araştırma / Açık
  Kaynak / Araştırma / Ürün / Türkiye — per prototype `srcMeta`), `is_default`,
  `status='active'`. Idempotent (`on conflict (slug) do update` of non-key fields).
  No Anthropic row (addendum §D).
- `supabase/functions/_shared/` **portable TypeScript** (no `Deno.*`, Web APIs
  only, each file < 500 lines): `url-safety.ts` (scheme/port/credentials/fragment
  rules, IP-literal + resolved-address range rejection via an injected resolver,
  redirect policy ≤ 3 with revalidation), `feed.ts` (RSS 2.0 + Atom parsing with
  a small pinned parser or a hand-rolled tolerant XML walker — state which and why;
  item → `{externalId, canonicalUrl, title, author, publishedAt, contentHtml,
  contentText, quality:'full'|'excerpt'}`; HTML sanitised to text; URL
  canonicalisation; `content_hash`), `rate-limit.ts` (window math only),
  `error.ts` (the error envelope from arch-001 §3), `supabase-admin.ts` (thin
  typed wrapper around `@supabase/supabase-js` service-role calls, injectable).
- `supabase/functions/sync-feeds/index.ts` (Deno glue): internal-secret auth
  (`X-Internal-Secret` compared in constant time to `Deno.env.get('AUTOMATIONS_SECRET')`),
  leases due sources, conditional GET (ETag / If-Modified-Since), parses,
  upserts on `(source_id, external_id)`, updates source fetch state/failure
  counters, records `private.ingestion_runs`, returns the arch-001 counts. One
  bad source/item never aborts the run. Concurrency ≤ 4, ≤ 20 sources/run.
- `supabase/functions/add-source/index.ts`: `verify_jwt` stays true (anon JWT);
  `X-Device-Id` uuid v4 required → `private.bump_rate_limit` (5/24h); body
  `{url, category, language, client_request_id}`; runs URL safety, fetches with
  limits (8 s, 1 MiB), accepts feed or discovers one `<link rel="alternate">`
  feed on an HTML page and validates it identically; upserts `aigundem.sources`
  (`status='pending'` until first sync) and returns `201 {source}` / `200` existing.
- `supabase/functions/deno.json` with an import map pinning
  `npm:@supabase/supabase-js@2` (exact version) and any parser.
- Jest tests (Node) for `_shared`: RSS + Atom fixtures (build them from the
  documented shapes: description-only feeds → `excerpt`; `content:encoded` →
  `full`), dedupe/upsert key derivation, URL canonicalisation, the full SSRF
  matrix (loopback, private, link-local, CGNAT, documentation, multicast,
  reserved, IPv6 local, credentials, `http:`, non-443 port, >3 redirects),
  rate-limit window math, partial-source failure isolation (pure function over a
  fake client). Wire into the Jest project P2 created for `supabase/tests`.
