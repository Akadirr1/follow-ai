**Role:** implementer. Read `agents/implementer.md`. Worker rules: no spawning, no
graph queries, no `.orchestrator/`, no task-status updates, never `git add`/
`commit`/`stash`/`checkout`. Runs only when both lanes are done (P7, P9 client;
P5 server) and the coordinator has deployed the Edge Functions and enabled cron.

## Goal
1. **Cross-layer tests** (Jest, fake network where needed): render/route tests
   that go screen → hook → repository → (fake) PostgREST/Edge, in **both** data
   modes; offline-cached feed after a network failure; pending summary →
   ready transition via polling; onboarding guard + notification scheduling
   path; theme persistence path through the real adapter shape.
2. **Env & bundle checks** as scripts under `scripts/` (Node, no new deps):
   `scripts/check-bundle.mjs` — runs `expo export --platform web` for the
   production mode, then scans `dist/` for forbidden substrings
   (`sk-ant`, `service_role`, `sb_secret`, `SUPABASE_SERVICE_ROLE_KEY`,
   `AUTOMATIONS_SECRET`) and for the presence of the view name (proof the
   supabase adapter bundles); `scripts/check-env.mjs` — validates
   `scripts/env.example` vs `src/config/env.ts` keys. Add `npm run check:release`
   running typecheck, all tests, both exports, and the two scripts.
3. **Production data mode**: default `EXPO_PUBLIC_DATA_MODE` to `supabase` for
   production builds (`app.config`/EAS profile or env defaulting in
   `src/config/env.ts` keyed on `__DEV__`), keep `mock` for dev/test; document
   in the report. Do **not** touch EAS credentials/app signing.
4. **Smoke checklist file** `agents/reports/p10-smoke.md`: the exact curl/app
   steps the coordinator runs against the live project (feed non-empty,
   search, add-source happy + SSRF-reject, request-enrichment 202/no_api_key,
   digest preparing), with expected outputs — so the human can repeat it.

## Allowed paths
Tests under `src/**/__tests__/**`, `app/**/__tests__/**`, `supabase/tests/**`;
`scripts/check-*.mjs`; `package.json` scripts only; `src/config/env.ts` (mode
defaulting only); `app.config.*` if you introduce it (say why); and your report
`agents/reports/p10.md` + `agents/reports/p10-smoke.md`.
## Forbidden
Feature changes, schema changes, screen copy changes, new runtime deps, deploy,
signing/store, `agents/**` except the two files above, `AGENTS.md`, `CLAUDE.md`.

forbidden substrings, view name present in the supabase-mode bundle · A3 test
totals before/after · A4 `git status` only allowed paths.
