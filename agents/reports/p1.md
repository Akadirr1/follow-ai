type Language = 'tr' | 'en';

## 5. Decisions

1. **Which Supabase key ships as the default — asked, not guessed.** The brief said
   "anon key from the facts file", but `facts-2026-08-21.md` contains only the
   *publishable* key while `arch-001.addendum.md` §F (authoritative on conflict)
   requires the *legacy anon JWT*, whose value was written nowhere I could read. I
   stopped and asked rather than guess or go fetch a credential. The coordinator chose
   option B and supplied the JWT; the publishable key stays in a comment in both files
   as the future replacement once Edge auth is revisited.

2. **`publishedAt` is ISO only; no display label crosses the seam.** The fixtures
   carry "2 saat önce"/"dün". The mapper resolves them against a fixed anchor,
   `MOCK_NOW_ISO = 2026-08-20T06:41:00Z` — the prototype's own editorial moment
   (digest dated 20 August 2026, detail card stamped 09:41 Istanbul). A `Date.now()`
   anchor would have made cursor tests depend on the clock. **Consequence P7 must
   plan for:** to keep prototype parity, P7 needs a Turkish relative-time formatter;
   the DTO deliberately will not hand it "2 saat önce".

3. **`bodyOriginal` + `summary.translationTr`, not `body`/`en`.** The original is
   always the source-language text; the Turkish rendering lives on the summary. So the
   Turkish source (`wz`) gets `bodyOriginal` = its Turkish body, `translationTr: null`,
   `translationState: 'not_required'` — arch-001 §6's "translation nullable only for
   TR" — and EN sources get `translationState: 'ready'`. That is exactly what the
   detail screen's Orijinal/Çeviri segment needs, and it makes "which text is the
   original" answerable without re-reading the language field.

4. **`Source.feedUrl` is nullable and Anthropic is inactive.** Anthropic publishes no
   feed (measured 2026-08-21) and the addendum ships six defaults. Rather than invent
   a URL, the mock catalog keeps all seven prototype entries but gives Anthropic
   `feedUrl: null`, `isDefault:false`, `isActive:false`; `listSources()` returns the
   six active ones. The prototype's Anthropic *article* stays in the fixture — the
   same shape as a source deactivated after its articles were ingested — so the
   5-article pagination and search fixtures are intact. A test asserts every active
   source has an `https://` feed URL.

5. **The mock digest is built from articles, not from `DIGEST` verbatim.** The
   prototype's digest is five hand-written entries whose titles differ from the
   articles and whose fourth (TechCrunch AI) has no article at all. A real
   `DigestItem` always points at an article, so the mock derives five items from the
   articles, reuses the prototype blurb when the source matches, and warns once about
   the entry it drops. The alternative — a nullable `articleId` — would model a state
   the real backend will never produce. No screen is affected: the Digest tab still
   reads `src/data/digest.ts` until P7.

6. **The supabase branch throws; methods never do.** `getRepositories('supabase')`
   throws `DataErrorException{code:'not_implemented'}` because the factory returns
   `Repositories`, not `Result<Repositories>` — there is no channel to report through,
   and handing back a set whose every call errors would let a build ship looking
   healthy while showing an empty app. `env.ts` already downgrades an incomplete
   supabase configuration to mock with a warning, so this cannot fire by accident: it
   needs an explicit mode plus both variables set.

7. **`env.ts` reads the three variables as literal `process.env.X` expressions.**
   Expo's babel plugin only inlines `EXPO_PUBLIC_*` when it sees the static member
   expression, so passing `process.env` around as an object would silently yield
   `undefined` in a production bundle. The resolver is a separate pure function, which
   is what the tests drive; the module-level read is the only impure line.

8. **`addSourceByUrl` validates then refuses.** It applies the rules the real
   `add-source` function will (https only, no credentials, no duplicates) and then
   returns `not_implemented`, because the mock cannot fetch or parse a feed.
   Fabricating a source row would make the mock claim a capability the app will not
   have until P3.

9. **`getArticle` has no prototype-style fallback.** The old store returned article
   `gd` for an unknown id (with a warning). The seam returns typed `not_found` and
   lets the caller decide — silently rendering a different article is worse at a data
   boundary than an explicit miss.

  tables is a design claim, not a measurement — the first real evidence comes in P6.

  Supabase accepts it, and whether Edge `verify_jwt=true` is satisfied by it, is the

  inserts shifting a page boundary.
