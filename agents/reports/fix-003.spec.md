**Role:** implementer. Read `agents/implementer.md`. Worker rules: no spawning, no

## Measured on the live project (coordinator, 2026-08-21 09:35)
`sync-feeds` v1 ingested 334 articles from 7 sources in 5.4 s. **Hugging Face
ingested 0**: its RSS items are `<title>`, `<pubDate>`, `<link>`, `<guid>` only —
no `<description>`/`<content:encoded>` — and `_shared/feed.ts` `mapRssItem`
counts them as `skipped.no_content` (sample: coordinator scratchpad
`fixtures/huggingface.xml`, 845 items, all content-less). The HF source is a
seeded default, so the catalogue currently promises a source that never shows an
article.

## Changes
1. **`supabase/functions/_shared/feed.ts`** — do not skip items that have a
   title, a link and a date but no content. Emit them with `contentText: ''`,
   `excerpt: ''` (or `null` where the row type allows), `quality: 'excerpt'`.
   Keep skipping items that lack title/link/date. Update `skipped` accounting
   (`no_content` stays as a counter only for the RSS/Atom cases where content
   was expected but empty after HTML stripping — say how you split it, or drop
   the counter). Ensure `toArticleRows` in `_shared/ingest.ts` passes
   `content_text: null` and `excerpt: null` for empty strings so
   `articles_full_requires_text`/length checks never trip, and that
   `content_hash` is still computed (over title + '').
2. **`supabase/functions/request-enrichment`** (+ `_shared/enrichment.ts`): when
   the article's `content_text` and `excerpt` are both empty/null, do **not**
   enqueue a job; answer `200 {status:'unavailable', reason:'no_content'}`
   (a terminal, cacheable client state — the client will show "Bu haber için
   özet üretilemiyor; kaynağa git"). Do not count it against the per-device
   miss limit. `process-enrichments` must also refuse such jobs defensively
   (`failed` with code `no_content`, no Claude call) in case one was enqueued
   earlier.
3. **Tests:** HF-shaped fixture (title/link/date/guid only) → items emitted with
   empty content and `excerpt` quality; ingest row mapping nulls; enrichment
   `unavailable/no_content` path; worker refuses content-less job without
   calling the client; existing suites unchanged.
