## 6. Implementer's decisions that deserve independent judgement (its report §5)

1. Search results do **not** mark an article read (matches prototype's
   `results[].open`, which omits `read`). Kept deliberately via `openArticle(markRead)`.
2. Unknown article id: `selectArticle` falls back to `arts[2]` equivalent **with a
   warn**; `openArticle` refuses with a warn.
3. Trash-in-saved keeps the prototype's 50 ms `_suppressOpen` guard because
   react-native-web bubbles nested presses; warns when it swallows an open.
4. `tab`/`view` removed from the store (expo-router owns navigation); `artId` kept.
5. Digest entries are static data (`src/data/digest.ts`), not derived from articles.
6. "Digest bildirimi" switch is decorative (no handler in prototype).
7. Search uses `toLocaleLowerCase('tr')` on both sides (Turkish dotless-ı correctness)
   — a deliberate deviation from the prototype's `toLowerCase()`.
8. Fonts: blank canvas until Inter loads; on failure renders with system font + warn.
9. `toastSeq` added so a replacement toast restarts the 2.2 s clock.
