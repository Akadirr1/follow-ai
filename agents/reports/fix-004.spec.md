**B1 — daily-cap deferral must not consume an attempt.** Leasing increments
`attempt_count` (0004 `private.lease_ai_jobs`); `requeueForCap` calls the
ordinary retry RPC which never restores it. Add a lease-token-guarded SQL
transition `aigundem.internal_release_ai_job_unattempted(p_job_id, p_lease_token)`
(+ public wrapper) that clears the lease, sets `available_at`, sets
`last_error_code='daily_cap'`, and decrements `attempt_count` by exactly one
(never below 0) — only valid while the lease token matches. Call it only from
the cap path in `_shared/enrichment.ts`; fix the false comment. Test with a
**stateful** fake that applies lease semantics (attempt++ on lease), starts a
job at attempt 4, denies the cap three times, and proves it is still leaseable
at attempt 4. Keep `no_content` terminal-failure from fix-003 intact.

**B2 — fetch deadline must cover the body.** `_shared/url-safety.ts safeFetch`:
one AbortController/timer alive through DNS, every redirect, and the full
capped body read; an abort during `reader.read()` → `{kind:'timeout'}`; cancel
every discarded (redirect/oversize) body. Test: a stream that emits headers
then never closes → `timeout` within the budget; redirect body cancelled.

**B3 — article body can close the prompt fence.** `_shared/prompt.ts`: strip/
encode both marker strings from `contentText` **before** truncation and

opening and one closing marker. Do **not** bump `PROMPT_VERSION` unless the
stable system text changes (it should not).

of `aigundem.internal_digest_prepare/finalize` in migration 0010 (keep
`#variable_conflict use_column` from 0009): `select … for update` on the digest
row first; select candidates once into a temp CTE/array and insert from that
single snapshot; `get diagnostics v_inserted = row_count`; mark `ready` only
when `v_inserted = 5`, otherwise delete the partial items and return
`preparing` with `missing = 5 - v_inserted`. Re-assert grants exactly as 0009
does. Extend `supabase/tests/sql-lint-p5.test.ts` (or a new `sql-lint-0010`)
to pin: `for update`, `get diagnostics`, the `= 5` guard, `search_path=''`,
revoke/grant lines.

enqueue" with one atomic wrapper `internal_enqueue_ai_job_charged(...)` (or
