## Goal
Move every screen off `src/store` + `src/data` and onto P6 hooks + P8 theme,
keeping mock mode pixel-equivalent and making supabase mode real:
- **Feed** `app/(tabs)/index.tsx`: `useFeed({category, enabledSourceIds})` with
  keyset pagination (infinite list, "Daha fazla" or onEndReached), loading /
  empty ("Bu filtrede haber yok") / error / **offline-stale** states (visible
  banner "Çevrimdışı — son güncelleme {relative}"), pull-to-refresh; source
  count and "N yeni" from data; header icon placeholder stays.
- **Article** `app/article/[id].tsx`: `useArticle(id)` + `useEnrichment(id)`:
  summary card shows the 3 bullets when ready, **"Özet hazırlanıyor"** with a
  subtle spinner when pending (and keeps the article excerpt/body readable);
  Orijinal/Çeviri segment hidden for TR sources and disabled until
  `translationState='ready'`; bookmark/read via user-state hooks; "Kaynağa git"
  opens `canonicalUrl` with `expo-linking` (`Linking.openURL`) — no toast.
- **Search** `app/search.tsx`: `useSearch(q)` (debounced 250 ms), recent
  searches from user-state, same empty/no-result strings; results open detail
  without marking read (prototype parity).
- **Saved** `app/(tabs)/saved.tsx`, **Sources** `app/(tabs)/sources.tsx`
  (defaults + custom; toggles → user-state; "Yeni kaynak ekle (RSS / URL)" opens
  a small sheet: URL + category picker → `SourceRepository.addCustom`, shows the
  typed error messages in Turkish), **Digest** `app/(tabs)/digest.tsx`
  (`useDigest()`: ready → 5 items; `preparing` → "Digest hazırlanıyor"), **Settings**
  (auto-translate from user-state; digest time sheet writes user-state — the
  notification scheduling itself is P9; remove the "Sürüm · Expo SDK 54" literal in
  favour of `expo-constants` version).
- **Tab bar / layouts** `app/(tabs)/_layout.tsx` + the remaining files from P8's
  list → `useTheme()`; no hard-coded hex outside `src/theme`.
- **Navigation guard** `src/navigation/openArticle.ts`: prevents the double
  push on rapid taps (rev-001 N1) — one Back returns to the origin.
- **Turkish relative time** `src/format/relativeTime.ts` ("2 saat önce", "dün",
  "3 gün önce", absolute after 7 days) with tests.
- **Delete** `src/store/**` and `src/data/**` only if nothing imports them after
  migration (`grep`); otherwise leave and list what still does. Keep the 35 store
  tests only if the store survives; if deleted, port the behaviour assertions to
  hook/render tests so coverage does not drop (reviewer will diff counts).
