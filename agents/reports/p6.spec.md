## Goal
Make `EXPO_PUBLIC_DATA_MODE=supabase` real, without auth:
- **Device identity** `src/identity/deviceId.ts`: uuid v4 generated once, stored
  via `src/storage/kv.ts` (`device_id`); exposed through a hook/provider; sent as
  `X-Device-Id` on every Edge call. Never sent to PostgREST reads.
- **Supabase client** `src/data-access/supabase/client.ts`: `@supabase/supabase-js`
  (exact pin) created from `env`, `auth: { persistSession: false, autoRefreshToken:
  false, detectSessionInUrl: false }` (no users in v1), `global.headers` with the
  device id for functions; `.schema()` **not** used — reads go to the public
  shims. Wrap every call in the seam's `Result`/`DataError`.
- **Repositories** `src/data-access/supabase/*.ts` implementing the P1
  interfaces: `FeedRepository` (keyset pagination on `(published_at desc,
  article_id desc)` using the view, `source_ids`/category filter; `getArticle`;
  `search` via the RPC), `SourceRepository` (defaults = rows with
  `is_default`; `addCustom` → Edge `add-source`), `EnrichmentRepository`
  (`request` → Edge `request-enrichment`, mapping `queued/no_api_key` to the
  seam's `pending` state), `DigestRepository` (latest `ready` digest + items;
  when none → `{status:'preparing'}`). Map DB rows → DTOs in one mapper file;
  `summary` DTO: `translationState` becomes `'pending'` when `summary_ready=false`.
- **Local user state** `src/user-state/*`: enabled source ids (defaults on
  first run), saved/read article ids with timestamps, auto-translate, digest
  time/enabled, onboarding flag, recent searches — in SQLite KV (JSON values,
  versioned key prefix `v1:`), exposed via small hooks with optimistic updates.
  No server round-trip for any of it.
- **Server-state layer**: `@tanstack/react-query` (+ `persist-client` and an
  `AsyncStorage`-compatible persister over `kv.ts`), `QueryClientProvider`
  mounted in `app/_layout.tsx` *after* the theme gate; query keys versioned
  (`['v1','feed',…]`); persisted queries restored before first fetch; offline →
  cached feed renders with a visible stale flag; max age 7 days, cap the
  persisted feed at 200 articles. Mock mode must keep working with the same
  hooks (repositories from `getRepositories()`).
- **Hooks** `src/data-access/hooks.ts`: `useFeed(filter)`, `useArticle(id)`,
  `useSearch(q)`, `useSources()`, `useDigest()`, `useEnrichment(articleId)`
  (polls with `poll_after_seconds` while `queued`, stops after N tries with a
  warn). Screens are **not** migrated here (P7) — but add one tiny proof:
  nothing else changes visibly.
- **Env**: `src/config/env.ts` already validates the three `EXPO_PUBLIC_*` vars;
  extend only if a new non-secret var is needed (say so).
